# Regression checklist: demoblaze.com

Полная проверка после изменений в системе.

---

## Регистрация
- [ ] Успешная регистрация с уникальным username
- [ ] Ошибка при существующем username
- [ ] Ошибка при пустом username
- [ ] Ошибка при пустом пароле (сейчас баг — BUG-001)
- [ ] Ошибка при пустых обоих полях
- [ ] Форма закрывается по кнопке Close

## Логин
- [ ] Успешный логин
- [ ] Ошибка при неверном пароле
- [ ] Ошибка при несуществующем пользователе
- [ ] Ошибка при пустых полях
- [ ] Форма закрывается по Close

## Логаут
- [ ] Логаут завершает сессию
- [ ] После логаута недоступны функции авторизованного пользователя

## Каталог и карточки товаров
- [ ] Главная страница: все товары загружаются
- [ ] Категории фильтруют корректно (Phones, Laptops, Monitors)
- [ ] Карточка товара: название, описание, цена отображаются
- [ ] Кнопка "Add to cart" работает
- [ ] Кнопка "Home" возвращает на главную

## Корзина
- [ ] Добавленный товар отображается
- [ ] Delete удаляет товар
- [ ] Total считается правильно
- [ ] Дублирование товара (BUG-002)
- [ ] Пустая корзина отображается корректно

## Оформление заказа
- [ ] Place Order открывает форму
- [ ] Total совпадает с суммой корзины
- [ ] Заказ с заполненными полями принимается
- [ ] Пустые поля — валидация (BUG-003, частично не работает)
- [ ] Поле Credit card — валидация формата (не реализована)
- [ ] Close закрывает форму без оформления

## Contact форма
- [ ] Форма открывается по ссылке Contact
- [ ] Успешная отправка с заполненными полями
- [ ] Форма закрывается по Close
