# Smoke-тест: demoblaze.com

Быстрая проверка основных функций перед регрессией. Если хоть один пункт не прошёл — стоп, смотрим логи.

---

## Авторизация
- [ ] Сайт открывается без ошибок
- [ ] Кнопка Sign Up открывает модалку
- [ ] Регистрация нового пользователя — успешно
- [ ] Логин зарегистрированным пользователем — username отображается в навигации
- [ ] Логаут — навигация возвращается в исходное состояние

## Каталог товаров
- [ ] Главная страница загружает список товаров
- [ ] Фильтр "Phones" — показывает только телефоны
- [ ] Фильтр "Laptops" — показывает только ноутбуки
- [ ] Клик по товару — открывается карточка

## Корзина
- [ ] Кнопка "Add to cart" работает, появляется alert
- [ ] Товар отображается в Cart
- [ ] Кнопка "Delete" удаляет товар

## Оформление заказа
- [ ] Кнопка "Place Order" открывает форму
- [ ] Заполненная форма принимается, появляется подтверждение
