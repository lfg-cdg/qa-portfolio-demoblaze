# Тестирование demoblaze.com

Это мой учебный проект — тестировал интернет-магазин demoblaze.com.
Внутри: тест-кейсы, чеклисты и баг-репорты которые нашел в процессе.

Использовал: ручное тестирование, баги описал в markdown.

## Структура

```
├── test-cases/       # тест-кейсы по модулям
├── bug-reports/      # найденные баги
└── checklists/       # smoke и regression чеклисты
```

## Модули

- Регистрация
- Логин / логаут
- Карточка товара
- Корзина
- Оформление заказа
- Contact форма
