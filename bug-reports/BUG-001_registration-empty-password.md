# BUG-001 — Регистрация проходит с пустым паролем

**Статус:** Open
**Severity:** High
**Priority:** High
**Дата:** 2026-03-14

---

## Описание

При регистрации нового пользователя поле "Password" можно оставить пустым — система всё равно создаёт аккаунт. После этого войти в аккаунт с пустым паролем тоже получается.

---

## Шаги воспроизведения

1. Открыть demoblaze.com
2. Нажать "Sign Up"
3. Ввести уникальный username
4. Оставить поле Password **пустым**
5. Нажать "Sign up"

---

## Ожидаемый результат

Появляется сообщение об ошибке: поле пароля обязательно для заполнения.

## Фактический результат

Показывается alert "Sign up successful." — аккаунт создан с пустым паролем. Войти в него тоже можно.

---

## Окружение

- Browser: Chrome 133
- OS: Windows 11
- URL: https://demoblaze.com

---

## Дополнительно

Это потенциальная уязвимость — пользователи могут случайно создать аккаунт без пароля.
